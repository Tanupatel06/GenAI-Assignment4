# 📂 GenAI - Assignment 4: File Handling in Python

## 📌 Overview
This file contains the solutions for **GenAI Assignment 4**, focusing on **File Handling in Python**. The assignment covers creating, reading, writing, appending, and safely handling files using Python's built-in file operations.

The project also includes a mini project that generates a discounted price report and exports it into a text file.

---

# 🎯 Learning Objectives

- Understand Python file handling.
- Read and write text files.
- Append data to existing files.
- Process file data using loops and lists.
- Generate reports from stored data.
- Handle missing files safely.
- Build a simple file-based mini project.

---

# 🛠 Technologies Used

- Python 3.x
- VS Code / PyCharm
- Text Files (.txt)
